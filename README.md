# 作品台

访问地址：https://118.25.109.46/zuopintai/

常规作品集版式：简洁页头、横向分类、紧凑搜索和作品封面网格。移除侧栏、点阵画布、居中大标题和对话式搜索区，使作品更早出现在首屏。延续石墨灰与浅绿色配色，保留原有 7 个作品、描述、分类和目标链接。

点击横向分类即可切换对应作品；桌面分类显示实际数量，手机单行展示所有分类，结果数量随筛选更新。切换分类保留搜索关键词；空状态提供一键重置。支持网格和列表视图，并在本机记住选择；存储不可用时仍可正常操作。桌面三列、平板两列、手机单列。

按 `/` 聚焦搜索，按 `Escape` 清空输入，提交搜索滚动到作品列表。支持键盘操作、可见焦点、减少动态效果偏好及剪贴板失败回退。批量打开受浏览器弹出窗口策略影响，页面会提示；每张卡片保留独立打开链接。

作品封面是轻量 HTML/CSS 绘制的主题示意，不是真实产品截图；不加载外部图片、字体、分析服务或第三方运行时。

项目为独立静态页面，无构建依赖。在项目目录运行 `python3 -m http.server 8080` 预览。`index.html` 为页面结构，`styles.css` 为响应式样式，`works.js` 为现有作品数据，`app.js` 为交互与装饰封面。发布需同时携带这四个文件。

发布顺序：先将源码提交并推送到 GitHub，再备份腾讯云 `/opt/my-resource-page/dist/zuopintai/`。上传完整版本至同一文件系统的临时目录，核对新旧文件摘要后，使用 Linux `renameat2(RENAME_EXCHANGE)` 原子交换目录；无需重启服务。保留交换后的旧目录与压缩备份。回滚需恢复整套 HTML、CSS、JS 文件，不能仅恢复入口。

2026-11-03 验证：在本机 Chrome 检查桌面、手机网格及列表截图；覆盖 320、390、768、1024、1440、1920 像素宽度，两种视图均无横向溢出。交互检查覆盖分类数量与选中状态、组合搜索、空状态重置、视图持久化、键盘操作、真实剪贴板读写及复制回退。检查批量打开的请求参数和外链安全属性；实际批量弹窗仍由浏览器策略决定。
